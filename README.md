# ミライと自由研究

小学生向けの **生成AIリテラシー・ノベルゲーム**です。

AIアシスタント『ミライ』と自由研究を進めながら、返ってきた答えの中の
**おかしなところを赤ペンで見つけて直す**ことで、生成AIとのつきあい方を学びます。

## あそびかた

1. ミライに出す質問を、3つの選択肢から選ぶ
2. 返ってきた答えの中の **おかしいところをクリック**して指摘する
3. あたりなら「はなまる」。ミライが訂正してくれる
4. いつでも「先生に出す」で提出でき、**深めた度合い × 指摘の完遂率**で採点される

見のがしたまちがいは、提出後の講評で「レポートにのこったまちがい」として全文と解説が返ります。

## 学べること

- **ハルシネーション** — 体長・年代などの数値の誤り、実在しない書名
- **個人情報・肖像権** — 氏名／学校／住所、友だちの顔写真、写真の背景からの場所特定
- **著作権・不正** — 既存キャラの模倣、AI作品のコンクール応募、丸写し、使用を隠すこと
- **安全** — 川に入る・野生生物を捕る・川の水を飲む等、AIが平然と勧める危険な助言
- **検証の作法** — 「AIに『合ってる?』と聞いても検証にならない」「AIは責任を取れない」「出典を書く」

良い質問を選んでも誤りは必ず混ざる設計にしてあり、
「良いプロンプト＝正しい答え」という誤解を体験的に崩します。

結果画面の末尾に「先生・おうちの方へ」として、各問のねらいと採点設計を記載しています。

## 使い方（授業・家庭）

`index.html` を開くだけで動きます。1ファイル完結で、外部への通信は一切ありません。
オフラインでも動作します。

- 効果音は Web Audio API による合成音（音声ファイル不要）。
  ヘッダーの 🔊 ボタンでミュートでき、設定は保存されます
- 音はブラウザの制限により、最初のクリック／タップまで鳴りません
- `prefers-reduced-motion` が有効な端末では演出を停止し、内容のみで遊べます
- ライトテーマ／ダークテーマの両方に対応
- 2〜3回くり返し遊ぶと、選択肢と誤りの組み合わせをひととおり体験できます

## 技術メモ

- 依存ライブラリなし。HTML / CSS / JavaScript のみの単一ファイル
- キャラクターと「はなまる」は SVG、紙吹雪は Canvas、効果音は Web Audio で生成
